# Dashboard de E-commerce com Dash

Este é um exemplo básico de dashboard de e-commerce utilizando **Python**, **Dash** e **Plotly**. O objetivo desse projeto é fornecer uma visualização interativa para monitoramento de dados de vendas de um e-commerce.

## Funcionalidades

- **Total de Vendas** e **Receita Total**: Exibe o total acumulado de vendas e a receita total do e-commerce.
- **Vendas por Produto**: Gráfico de barras que mostra o número de vendas por produto.
- **Receita por Categoria**: Gráfico de pizza que exibe a distribuição da receita por categoria de produto.

## Tecnologias Utilizadas

- **Python**: Linguagem de programação.
- **Dash**: Framework para criação de dashboards interativos.
- **Plotly**: Biblioteca para visualizações interativas.
- **Pandas**: Biblioteca para manipulação de dados em forma de tabelas (DataFrames).
